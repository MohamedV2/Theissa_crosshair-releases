# TheCrosshair

Windows crosshair app · Developed by **issa_rahim**

[Download TheCrosshair-Setup.exe](https://github.com/MohamedV2/Theissa_crosshair-releases/releases/latest/download/TheCrosshair-Setup.exe)

Install once, then open the **TheCrosshair** shortcut. Existing installations download updates, save the current design, install silently, and restart automatically. The shortcut stays the same; the version changes inside the app. You do not need a new Setup download for each release.

Discord Rich Presence shows **TheCrosshair** and **Developed by issa_rahim** while the app is open. Discord desktop must be running and activity sharing enabled. You can switch this off in TheCrosshair → Settings → Discord activity.

This repository contains downloads and update metadata only. Source code is maintained in a separate private repository.
